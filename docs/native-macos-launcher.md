# 本机虚拟 Mac 桌面与启动器

Apple Silicon 主机使用本机 macOS 客机时，侧栏的“虚拟机启动器”提供“启动并打开桌面”、关闭窗口及停止虚拟机。原工作台仍可切回。

完整桌面使用现有 VZ 虚拟机的原生 `VZVirtualMachineView`，画面与键鼠不经过工作台的 SSH 窗口采集/输入转发。虚拟机运行后即可打开桌面，不必等待客机 SSH 或浏览器服务就绪。SSH 仍用于后台客机身份、项目及网络验证；网络检查未完成时，外网继续保持关闭。

## 使用

- 选择“启动并打开桌面”。已运行时选择“打开桌面”，不会创建另一台虚拟机。
- 关闭原生窗口或选择“关闭桌面窗口”，虚拟机继续运行；再次打开会连接同一实例。
- 停止前先保存客机中的文件，再选择“停止虚拟机”并确认。磁盘、账户及项目数据保留。
- “打开工作台”和侧栏“虚拟机启动器”可在两种界面间切换，已打开的桌面窗口保留。
- 退出启动器关闭其桌面租约，后台虚拟机及受控网络管理继续运行。停止虚拟机需使用停止操作。

账户锁定、控制服务退出或租约连接关闭会关闭原生桌面。桌面入口仅对可信的本机窗口开放，不能经远程连接或手机入口访问。完整桌面打开时，工作台暂停同一客机的窗口采集，避免重复渲染与输入。

## 从源码构建

按[贡献指南](../.github/CONTRIBUTING.md#macos-源码构建)准备 Go、uv 和原生构建依赖。

```sh
# 含侧栏启动器入口的普通 Cage.app
bash scripts/build-app.sh

# 默认显示启动器的独立 Cage VM Launcher.app
bash scripts/build-app.sh --vm-launcher
```

标准打包流程会生成、签名并验证嵌套的 `CageVM.app` 运行器，沿用现有虚拟机配置与虚拟化权限。独立启动器采用手动更新，不会被普通工作台发行包自动覆盖。

本机改造构建可使用 `CAGE_LOCAL_BUILD=1`，并通过 `CAGE_BUILD_VERSION`、`CAGE_BUILD_NUMBER`、`CAGE_BUILD_OUTPUT` 指定版本与输出。此标记使该包采用手动更新；官方普通发行构建的更新流程保持不变。

## 故障行为与验证范围

- 客机 SSH 可能先于浏览器 LaunchAgent 就绪。显式启动对幂等配置同步最多等待 30 秒，拒绝的配置不重试。
- 失效通道上的只读查询可重连一次；点击、按键、导航、文件操作不会因为回复丢失而自动重放。
- 健康检查继续验证客机身份与网络门槛，已就绪时不再每轮向 GUI 队列重复写创建配置。
- Lima 初始化等待 cidata 的 guest-agent 可执行文件出现，最多 60 秒；缺失时仍失败，不伪造启动完成标记。

本功能的原生桌面仅在 Apple Silicon/macOS 主客机上验收；不代表 Intel、Windows、Linux 原生桌面支持，也不保证 Claude 登录、人机验证或第三方账号服务可用。
